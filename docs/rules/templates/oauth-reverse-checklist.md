# 逆向检查清单：<provider 名> <客户端版本>（日期）

> 用途：新增一个需要 OAuth 逆向的服务商时复制本模板，逐节执行。
> 纪律：能不动态插桩就不插桩；带凭据联调只允许一次真实登录；红线（E 节）任一不过即停工。

## A. 静态情报（无网络）
- [ ] A1 GitHub 社区仓库检索：历史协议面/信封/域名，标注停更时间（历史参照 ≠ 协议真相）
- [ ] A2 本机安装包：product.json / package.json / manifest（版本、域名、client_id、URL scheme）
- [ ] A3 二进制 strings：路由族提取（本地 RPC 与云端路由按命名空间分辨）
- [ ] A4 官方日志/本地缓存：登录日志、网络日志（头组清单）、state.vscdb 类缓存
- [ ] A5 凭据存储排除法：明文文件 / OS 凭据管理器 / 加密存储 / 仅内存（按此顺序证伪）

## B. 无凭据在线探测（探测边界声明先行：次数、间隔、全部只读）
- [ ] B1 端点存活矩阵：登录/token/refresh/account/chat 五面，错误信封逐条落证据
- [ ] B2 错误码指纹：假 client_id / 假 auth_code / 无 token 三层失败形态
- [ ] B3 头校验面：UA/必填头逐项二分（规则 vs 迷信，迷信头注释标注）
- [ ] B4 限流基线：连续探测触发限流的间隔（写进脚本的探测纪律，如 ≥20s）
- [ ] B5 预注册预测表：每条假设写明预测与判定标准（HIT/MISS 制度；否定发现同样成文）

## C. 带凭据联调（一次真实登录解锁，仅此一步）
- [ ] C1 登录流全证据落盘（脱敏后入库：`<redacted:字段>` 原位替换）
- [ ] C2 token 权限边界矩阵：token × 端点族（含计费/额度族）——决定 UI 诚实标注档位
- [ ] C3 refresh 轮换语义实测：旧 refresh 复跑 / 旧 access 复用 / 字段名核对
      → 产出注册表声明 `refreshRotation: rotating | non-rotating | unknown`
- [ ] C4 签名/指纹头分级：
      - 可自控 → 自持密钥走完整流（如 P-256 自签 + 公钥注册）
      - 无害 → 补齐对齐官方日志形态
      - 不可伪造 → 省略并文档化（见头即校验的服务端强制头绝不伪造，发了必 400）
- [ ] C5 额度/配额信号：数值额度 API 探测（决定真实/估算档）

## D. 落地与回归
- [ ] D1 骨架装配：core/oauth-flow.js 方言声明（端点/错误信封/轮换语义/authUrl 白名单）
- [ ] D2 离线 verify 脚本（mock 上游：投毒 authUrl / 非法基址 / 分片 body / 临期刷新竞态）
- [ ] D3 规则文档（docs/rules/<provider>.md）+ 未解表（每条写解锁条件）
- [ ] D4 README/免责声明更新；改派披露通道就位（如 SSE 注释行）

## E. 红线确认（任一不过即停工）
- [ ] E1 不提取/解密官方客户端本地凭据存储
- [ ] E2 不伪造不可复刻的服务端强制签名头
- [ ] E3 不分发任何真实凭据；仓库零 secret；探测证据落盘前必脱敏
- [ ] E4 不做多账号聚合/指纹轮换/额度转售
- [ ] E5 登录仅由用户显式动作发起
